# Issue 118 spatial baseline

Spatial search reads only the active catalog serving bundle. Society/place
coordinates, geometry, containment, adjacency, geo-cell membership, and
proximity facts are derived offline and loaded into typed serving indexes.

Required spatial predicates fail closed without durable evidence. A resolved
place may use the bundle-wide candidate cohort when no geo-cell topology is
available, but the spatial evaluator must still prove the predicate for each
admitted property. Missing topology is diagnostic state, never a buyer claim.

The reproducible baseline is the frozen query bank plus the controlled
conversational, geo-cell, serving-bundle, and search-efficiency contracts.
